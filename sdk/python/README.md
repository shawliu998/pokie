# Qurio SDK

Typed Python, JSON CLI and bounded stdio MCP access to retained Qurio
quantitative research evidence.

```bash
pip install qurio_sdk-0.1.0-py3-none-any.whl
pip install 'qurio_sdk-0.1.0-py3-none-any.whl[mcp]'
```

Set `QURIO_API_URL`, `QURIO_WORKSPACE_ID` and `QURIO_ACCESS_TOKEN`, then use
`qurio datasets`, `qurio runs`, or `qurio-mcp`.
